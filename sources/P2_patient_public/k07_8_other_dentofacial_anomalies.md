## Verified takeaways

- Malocclusion can come from jaw-tooth mismatch, jaw shape differences, or other structural bite problems.
- Orthodontics is used to correct crowded, crooked, or poorly fitting bites when the teeth are the main issue.
- Some jaw and face balance problems need orthognathic surgery when orthodontics alone cannot fix the bite.
- K07.8 should stay an overflow bucket for a specified dentofacial anomaly that does not fit the more detailed K07 subgroups.

## Scope note

- Use this only when the chart names a dentofacial anomaly but the pattern does not fit jaw-size, arch relationship, tooth position, functional, or TMJ buckets.
- This is not a general malocclusion code.
- If the chart is vague rather than specific, prefer K07.9 instead of K07.8.

## Safe wording

- `K07.8`: use when another dentofacial anomaly is explicitly documented and the note gives enough detail to say it is not one of the named subgroups.

## Limits / ambiguities

- Do not use this for crowding, overbite, open bite, mouth breathing, or TMJ pain if a more specific K07 code exists.
- If the record only says "bite problem" or "jaw problem" without detail, that is more likely `K07.9`.
- This code is best treated as a clinician-described exception bucket, not a catch-all for unclear dental alignment.
