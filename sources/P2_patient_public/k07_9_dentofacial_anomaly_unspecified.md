## Verified takeaways

- Many dentofacial alignment problems are first noticed in a routine dental exam.
- Orthodontic treatment can improve bite alignment, and jaw surgery may be used when orthodontics alone is not enough.
- The unspecified bucket is safest when the record confirms a dentofacial anomaly but does not name the exact pattern.
- A vague chart label should not be upgraded to a more specific K07 subtype without supporting detail.

## Scope note

- Use this only when the note clearly says there is a dentofacial anomaly but does not describe which one.
- If the chart provides enough detail to choose a more specific K07 code, do that instead.
- Do not use this just because a patient was referred to orthodontics.

## Safe wording

- `K07.9`: use when the chart says dentofacial anomaly, malocclusion NOS, or a similar unspecified bite/facial alignment problem without more detail.

## Limits / ambiguities

- This is a fallback code, so it should be replaced if later documentation names the specific anomaly.
- If the issue is actually TMJ pain, jaw size, or a habit-related bite problem, use the matching K07 subgroup instead.
- Unspecified does not mean "minor"; it only means the record did not say enough to classify it more narrowly.
