## Verified takeaways

- K07.5 is a functional bucket: the bite problem is linked to how the mouth is used, not just tooth position.
- Public sources support links between malocclusion and habits such as thumb sucking, tongue thrusting, prolonged dummy use, and prolonged bottle use.
- Mouth breathing can be part of a malocclusion picture, and enlarged adenoids are a common reason children breathe through the mouth.
- Orthodontic review is still the main next step when a functional habit or breathing pattern is affecting the bite.

## Scope note

- Keep this note limited to function-related dentofacial anomalies.
- Do not use it for jaw-size mismatch, isolated tooth-position problems, or TMJ disorders.
- If the chart only says crowding or a bite problem without a functional cause, pick a more specific K07 subgroup instead of K07.5.

## Safe wording

- `K07.50`: use when the record explicitly says the jaw closes abnormally or the closing pattern is the problem.
- `K07.51`: use when abnormal swallowing, tongue thrust, or another swallow pattern is explicitly linked to the malocclusion.
- `K07.52`: use when mouth breathing is explicitly named as the functional cause, often with chronic nasal obstruction.
- `K07.53`: use when thumb sucking, finger sucking, dummy use, lip sucking, tongue habits, or a similar oral habit is the documented cause.
- `K07.58`: use when a functional dentofacial anomaly is documented but it does not fit the named subcodes.
- `K07.59`: use when the note says functional dentofacial anomaly but gives no further detail.

## Limits / ambiguities

- `K07.51` and `K07.53` can overlap clinically because tongue thrust is both a habit and a swallow-pattern issue.
- Mouth breathing can be a symptom, a cause, or both; only code `K07.52` when the record ties it to the bite problem.
- Do not infer K07.5 from crowding alone unless the clinician links the bite problem to a function, habit, or breathing pattern.
