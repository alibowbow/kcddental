권장 링크:

- `mfds_dur_dataset_info.md`
  - https://data.mfds.go.kr/
- `hira_dur_guide.md`
  - https://www.hira.or.kr/cms/guide_busi/03/03/index.html

입력 원칙:

- related_drugs, DUR 경고, 상호작용 문구는 MFDS/HIRA 구조화 데이터나 명시적 공식 안내가 있을 때만 추가합니다.
- 블로그/커뮤니티 기반 약물 주의문은 반영하지 않습니다.
